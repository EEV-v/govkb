# Project Knowledge Steward

Use this governed capability as the cold-start knowledge keeper for the project.

## Load References First

- Read `references/long-term-memory.md` before acting.

## Scope

- Keep stable repo workflows, conventions, verification commands, and project operating rules.
- Keep broad lessons only until a more specific governed capability exists.
- Record repeated specialized work as a candidate signal instead of turning this capability into a junk drawer.

## Memory Rules

- Store only reusable project knowledge that should help future assistant sessions.
- Avoid local environment trivia, one-off task status, report output, secrets, and scheduler maintenance details.
- Prefer short, action-oriented bullets with enough context to reuse.

## Candidate Skill Signals

- When repeated work does not fit an existing governed capability, preserve the signal under `.governed/candidates/`.
- Promote a candidate to a governed capability when the same area appears repeatedly or when a reusable workflow becomes clear.
