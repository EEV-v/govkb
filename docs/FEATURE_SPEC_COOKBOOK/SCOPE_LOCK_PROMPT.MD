# Scope Lock Prompt

Use this at an explicit checkpoint before engineering handoff.

## Output

- `docs/governed-skill-knowledge-framework/features/<FeatureSlug>/scope-lock.md`

## Rules

- Summarize accepted scope, non-scope, deferred items, resolved questions, and approved decisions.
- List remaining blocking questions or open decisions if any.
- Record tracker/reference status honestly.
- Do not mark scope locked if unreconciled feedback remains.
- Scope can be locked for a named slice even when later public-launch scope remains deferred.
