# Engineering Handoff Prompt

Use this after `scope-lock.md` exists.

## Output

- `docs/governed-skill-knowledge-framework/features/<FeatureSlug>/spec-handoff.md`

## Rules

- State whether engineering cookbook work can start.
- Link source artifacts: `business.md`, `business-context.md`, `context.md`, `spec-brief.md`, `open-questions.md`, `decision-log.md`, and `scope-lock.md`.
- Summarize accepted scope, deferred scope, approved decisions, known risks, and verification baseline.
- Name the engineering cookbook entry point: `docs/COOKBOOK/COOKBOOK.MD`.
- If handoff is for a slice, say exactly which slice is ready.
- If blockers remain, set handoff readiness to `No`.
