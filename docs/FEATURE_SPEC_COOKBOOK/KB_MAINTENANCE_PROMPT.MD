# Knowledge Base Maintenance Prompt

Use this after a completed review/reconciliation round when the round produced reusable process lessons.

## Output

- `docs/FEATURE_SPEC_COOKBOOK/spec-knowledge-base.md`

## Rules

- Add only reusable cross-feature lessons.
- Do not copy raw feature-specific scope, stakeholder wording, private tracker links, or raw feedback.
- Prefer compact bullets that improve future spec convergence.
- Keep GovKB-specific lessons separate from public Marketplace or extension-specific decisions unless they are broadly reusable.
